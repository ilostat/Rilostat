# Package index

## Essential functionality

Access, search, label and manage ILOSTAT data using the native Rilostat
interface.

- [`get_ilostat()`](https://ilostat.github.io/Rilostat/reference/get_ilostat.md)
  : Read ilostat Data
- [`get_ilostat_dic()`](https://ilostat.github.io/Rilostat/reference/get_ilostat_dic.md)
  : Read ilostat Dictionary
- [`get_ilostat_toc()`](https://ilostat.github.io/Rilostat/reference/get_ilostat_toc.md)
  : Read ilostat Table of Contents / workflow
- [`label_ilostat()`](https://ilostat.github.io/Rilostat/reference/label_ilostat.md)
  : Switch ilostat codes and labels
- [`clean_ilostat_cache()`](https://ilostat.github.io/Rilostat/reference/clean_ilostat_cache.md)
  : Clean ilostat Cache
- [`distribution_ilostat()`](https://ilostat.github.io/Rilostat/reference/distribution_ilostat.md)
  : Switch ilostat to distribution
- [`runapp_ilostat()`](https://ilostat.github.io/Rilostat/reference/runapp_ilostat.md)
  : Play with ILOSTAT data apps
- [`Rilostat-package`](https://ilostat.github.io/Rilostat/reference/Rilostat.md)
  [`Rilostat`](https://ilostat.github.io/Rilostat/reference/Rilostat.md)
  : R Tools for ilostat Open Data

## SDMX

SDMX-oriented access to ILOSTAT observation data, structures, codelists
and dataflows, with SDMX-ML 3.1 and SDMX-JSON 2.1 support for structural
resources.

- [`get_ilostat_sdmx()`](https://ilostat.github.io/Rilostat/reference/get_ilostat_sdmx.md)
  : Retrieve ILOSTAT data using an SDMX-oriented interface
